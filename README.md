# LunaAir
### Intelligent Environmental and Vocalization Monitoring System

## Overview

LunaAir is an ongoing personal project focused on developing an intelligent monitoring system for my pet bird, Luna, using a Raspberry Pi Pico.

Birds have sensitive respiratory systems and can be affected by changes in environmental conditions. Additionally, changes in vocalization patterns may provide useful information about their behavior.

The goal of LunaAir is to develop a system that continuously monitors environmental conditions and uses machine learning to distinguish between different vocalizations, alerting the owner when potentially concerning conditions are detected.

## Project Objectives

### Temperature Monitoring
- Continuously monitor ambient temperature near Luna's cage.
- Detect temperatures outside predefined safe ranges.
- Trigger alerts when temperatures become too high or too low.

### Air Quality Monitoring
- Monitor airborne particulate concentrations.
- Detect potentially concerning changes in air quality.
- Trigger alerts when pollution levels exceed configured thresholds.

### Vocalization Recognition
- Collect audio samples of Luna's vocalizations.
- Train a machine learning model to distinguish normal chirping from scream-like vocalizations.
- Detect unusual vocalization patterns.
- Notify the owner when potentially concerning sounds are detected.

The vocalization classifier is intended to recognize sound patterns, not diagnose pain or illness.
